# Prompt: levantamento

Pontos de partida. Adapte ao seu projeto.

```
Leia somente a área do código relacionada a este pedido: {pedido}.
Não altere nada. Entregue:
1. O que existe hoje, com os caminhos dos arquivos.
2. Uma tabela "afirmação do pedido × o que o código mostra".
3. Riscos e pontos de extensão.
4. O comando de teste e o resultado atual (linha de base).
Marque como "suposição" tudo o que não puder confirmar no código.
```
