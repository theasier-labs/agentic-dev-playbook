# Checklist de revisão

Antes de aceitar uma mudança feita por um agente:

- [ ] Li a **diferença do código** de cada arquivo alterado, inclusive os de tela e configuração.
- [ ] Nenhum arquivo foi apagado ou movido sem que eu soubesse por quê.
- [ ] Os testes novos falham sem a mudança e passam com ela.
- [ ] Os testes que já existiam continuam iguais à linha de base.
- [ ] Nenhum número, limite ou data foi inventado; os que existem têm fonte.
- [ ] Nada sensível (chaves, URLs internas, dados de pessoas) entrou no código ou nos documentos.
- [ ] A ordem de publicação está descrita, com a reversão.
- [ ] Sei responder: "o que acontece se isso falhar em produção?"
